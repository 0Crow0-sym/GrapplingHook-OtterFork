# Grappling Hook — Otter Fork

An Otter Creek maintained fork of **GrapplingHook** by **Corewin**, updated for compatibility with the Otter Creek server and its current mod configuration.

## About

This repository contains the compiled files for the Otter Creek fork of GrapplingHook.

The original mod was created by **Corewin**.
**aRTyficial** is credited as a contributor to the Otter fork.

This fork exists to maintain compatibility with the Otter Creek server and to preserve access to the version used by the server.

## Original Mod

* **Original Author:** Corewin
* **Original Mod:** GrapplingHook
* **Original Mod ID:** `grapplinghook`
* **Otter Fork Mod ID:** `grapplinghookotterfork`

The Otter fork uses a separate Mod ID so it can coexist with or be distributed independently from the original mod.

## Version

**Otter Fork:** 1.2.2
**Game Dependency:** Vintage Story 1.22.3

## Installation

1. Download the latest release from this repository.
2. Place the mod ZIP into your Vintage Story `Mods` folder.
3. Do not extract the ZIP.
4. Start Vintage Story and allow the mod to load.

For a multiplayer server, the server and connecting clients should use the version required by the server.
